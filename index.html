RIFD

Capstone

RIFD (رفد, Arabic for "to support") is an Arabic-first, trauma-informed multi-agent AI assistant offering safe, private, and culturally aligned first-line support for domestic-violence survivors in Saudi Arabia, a companion that guides users toward professional help, never a replacement for it.

  • 8-stage multi-agent pipeline on LangGraph: router, risk screening, tone analysis, therapist drafting, legal & cultural review, and translation.
  • Layered safety: every reply is checked for safety, tone, cultural fit, and legal accuracy before the user ever sees it.
  • RAG-grounded on a curated KSA knowledge base of rights, services, and trauma-informed coping strategies.
  • Safety-by-design UX: a Quick-Exit / decoy screen and clinician-only report export with consent.
  • Arabic-first & bilingual, with full voice input and output (STT / TTS) for accessibility.
  • Benchmarked against a single-model baseline and consistently avoided unsafe outputs.
  • Arabic-first
  • LangGraph
  • Multi-agent

Warm & Cold Game

Computer Vision Code

A real-time, hands-free guessing game built with Python, OpenCV, and MediaPipe. You guess a hidden number (1 to 10) by holding up fingers, read live via hand-landmark pose estimation, with "Warm" or "Cold" hints. The twist: an MDP (Markov) model picks each new target from a probability distribution based on your current guess and the difficulty, so the game adapts as you play, alongside dynamic tries and a leaderboard.

  • Python
  • OpenCV
  • MediaPipe
